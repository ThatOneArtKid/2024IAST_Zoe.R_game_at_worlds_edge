## Game
At World's Edge was a project I created for an assignment in IST/multimedia, with the assets (sprites, music, tiles, etc) being for the multimedia portion, and the code itself being for the IST portion. 

Due to the time constraints, it ended up becoming more of a demo than the work in progress of a fully fledged game, as I was unable to finish certain aspects such as level design.

As such, I'm treating it as more of an attempt at figuring out 2D platforming mechanics (and general game mechanics) in Unity (and coding with C#) than an attempt at making a video game. 

## Features
### Gameplay
 - Basic movement controls (left/right movement and jumping), as well as more complex movement (wall jumping)
 - A health system (the ability to take damage and heal)
 - Dying
### Visuals and sound
 - Sprites, tiles, backgrounds, etc
 - Menu screen + game over screen
 - Parallax effects for the background
 - Music for each different screen (menu/levels/game over)
